Before you start

  • Test on the dev system only. It is a fresh copy of production (06 Oct 2026) — real customers and stock, nothing you do touches production.
  • Switch company with the workspace switcher (top-left). Stock owner = Smart Innosys; sister company / agent = Affirma (specialist Zilarahim).
  • Do the use cases in order; later ones use what earlier ones create. UC-21 onwards cover the latest changes (numbering, consignment terms, inventory, Stock Rules, dashboard, leave).
  • Products have no unit cost in this data, so anything priced “cost-plus” shows pending — use the price lists as described.
  • Good test items: SFCS000345, SSP-8030 (have MDA certificates) and A.4086.1, STRC1406C (no MDA).
  • Something not as expected? Note the use-case number, step and a screenshot.

UC-03

Correct machine details — Lots & Serial Numbers

Inventory manager / owner
One job, one place: quantities change only through New Movement; serial numbers and lots only on Lots & Serial Numbers. Stock Overview has no Edit (pencil) any more.
  1. Stock Overview → Main Warehouse → SWING 15 row. Look at the buttons on the right.
  2. Click # Serial numbers → it opens Lots & Serial Numbers filtered to that row. On one unit click Fix serial no., enter the correct serial and a reason, save.
  3. Change another unit's use (For sale ⇄ Company asset).
  4. On a unit entered by mistake click Remove, give a reason.
  5. Register serial numbers → choose Main Warehouse → SWING 15 → give the unit without a serial its number back. Try the dialog on a phone-width screen.
  6. Stock Overview → a row with quantity 0 and no serials → Remove row. Then try a row that still has stock.

UC-20

Your own item groups

Inventory manager · Case DO user
Groups are yours to define (any names, e.g. matching your case types: milh, evlt, pldd). A product can be in several groups, but every stock list shows it once — under its first group, or the group that matches the case type on a Case DO — and names its other groups on the row. Groups never change stock.
  1. Inventory → Item Groups. Add your groups (any name, any colour) and use ↑ ↓ to put them in the order you want.
  2. Under Products you hold, click a group chip on a product to put it in (+ evlt → ✓ evlt) or take it out. Give SWING 15 ✓ milh ✓ evlt ✓ pldd. (Or: a group's Add products search, or tick several products and Add selected to….)
  3. Open Inventory → Stock Overview, then Field Stock → a specialist.
  4. New Case DO → choose a specialist → tick case type milh, then untick it and tick evlt. Do not save.

UC-26

Stock Rules — record & flag, warn, enforce

Affirma · inventory manager + DO user (with and without the override)
Use a specialist and an item where you know what they hold. Put the rules back the way they were afterwards — Changes to these rules shows the old values.
  1. Inventory → Stock Rules. Set Record & flag, save. Record a Case DO's actual items with 1 more than the specialist holds.
  2. Set Warn. Record the same way.
  3. Set Enforce (no date). Record the same way as a user without “Record Case DO usage without enough stock”; then as a user with it.
  4. Under Other items used, add a catalogue item Taken from Main Warehouse; record.
  5. Add the item's group under Exceptions; record beyond stock again.
  6. Turn on When creating a Case DO; create a Case DO whose customer items the specialist doesn't hold.
  7. Set Enforce with Enforce from a date next week; record beyond stock.
  8. Shortfalls to reconcile → one shortfall → Mark resolved (Explained, with a note). Look at Ready to enforce?
