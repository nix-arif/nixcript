01

Overview

The Leave module lets you apply for, track, and manage leave applications — from annual leave to medical and emergency leave. Applications are submitted directly for Approver review; there is no draft or checker step.

Leave balances are calculated per calendar year based on your length of service. The system counts working days only (Monday to Friday) and prevents overlapping applications.

Every application gets a unique number: LV-YYYY-XXXX (e.g. LV-2026-0001). Use this number when following up with HR.

03

Your Leave Balance

Go to Human Resources → My Leave to see your balances for the current year. Each leave type shows:

Entitled

16

Days granted this year based on service

Carry Forward

5

Unused days brought over from last year

Used

4

Approved and consumed days

Available

17

Remaining days you can apply for

Available = Entitled + Carry Forward + Earned Credits + Opening Balance − Opening Used Days − Used − Pending

Days in Pending status are reserved from your balance until the application is approved or cancelled. Weekends are not counted in any balance.

What are “opening” days? They are set by HR on the Leave Balances page for people whose leave started before the system did, and they only appear if HR set them.
  • Opening balance adds days — leave a member already had left over from before the system (e.g. 5 unused days brought in when the company migrated).
  • Opening used days subtracts days — leave already taken before the system went live (e.g. 6 days taken January–June when the system started in July). It applies to that year only and does not carry forward.
04

How to Apply for Leave

1

Check Your Balance

Go to Human Resources → My Leave and verify you have enough available days for the leave type you need.

2

Click "Apply Leave"

Use the button at the top-right of the My Leave page to open the application form.

3

Select Leave Type

Choose from the available leave types in the dropdown. Only active types with sufficient balance are selectable.

4

Set Dates

Pick your start and end date. The system automatically calculates the number of working days (Monday–Friday only). Weekends and public holidays are excluded.

For half-day leave, enable the toggle and select AM (morning) or PM (afternoon). See Section 04a below.

5

Add Reason & Upload Document

Enter a reason for the leave. For leave types that require a supporting document (Medical Leave, Hospitalisation, etc.), upload the document before submitting. See Section 04b.

6

Submit

Click Submit Application. The status immediately becomes Pending and your Approver is notified. Days are reserved from your balance until a decision is made.

04a — Half-Day Leave

Half-day leave is only available for leave types that allow it (e.g. Annual Leave). It counts as 0.5 days against your balance.

  • Enable the Half Day toggle on the form
  • Select AM (you leave at noon) or PM (you arrive after noon)
  • Start date and end date must be the same day for a half-day application

04b — Document Upload

Certain leave types require a supporting document. The form will prompt you when a document is needed.

  • Medical Leave — upload your Medical Certificate (MC)
  • Hospitalisation Leave — upload hospital admission letter or discharge summary
  • Maternity / Paternity Leave — upload birth certificate or hospital document
  • Accepted formats: PDF, JPG, PNG
  • You can upload additional documents after submission from the application detail page
You cannot submit an application if the dates overlap with an existing Pending or Approved application. Cancel the existing application first if needed.

Roles & Responsibilities

Four roles take part in the leave process. Recording leave is a separate permission from approving it, so the person who records leave does not have to be an approver.

leave:apply

Applicant

Check leave balances
Submit leave applications
Upload supporting documents
Cancel own Pending or Approved applications
View own application history

leave:approve

Approver

View all pending applications in the Approvals queue
Approve → Approved (with optional comment)
Reject with reason → Rejected
See the applicant's balance for that leave type before deciding — total available, used, pending, and what remains before and after this request (red if it would go below zero)
Cancel any application on behalf of applicant
Cannot approve their own application

leave:record

Leave Recorder (HR)

Record leave for a member who took it but did not apply (see 08)
Attach the supporting document (e.g. the MC)
Cannot record leave for themselves
Does not need to be an approver, and recording does not let them approve or reject anyone's leave

leave:summary

Leave Analyst (HR / Management)

Open Leave Summary — every member's balance, taken, pending and patterns
Export the summary to Excel

Quick setup bundle Leave Administrator (Admin → Access Control) gives record, summary, report and leave settings together. Approving leave is granted separately in Admin → Approvals.

07

Cancelling a Leave Application

You can cancel an application in either Pending or Approved status. The balance is restored automatically.

Cancel a Pending Application

The application has not yet been reviewed.

  1. Open the application from My Leave
  2. Click Cancel Application
  3. Confirm the cancellation
  4. Status changes to Cancelled — pending days are returned to your balance

Cancel an Approved Application

The leave has been approved but you no longer need it.

  1. Open the application from My Leave
  2. Click Cancel Application
  3. Confirm the cancellation
  4. Status changes to Cancelled — used days are returned to your balance

Notify your manager separately if cancelling approved leave affects work coverage.

Cancelled applications cannot be reopened. Submit a new application if you still need the leave.
08

Recording Leave for a Member

For leave a member took but never applied for in the system — e.g. they were on MC and sent the slip by WhatsApp or email. Only someone with the leave:record permission can record it (it is separate from approving), and never for themselves. It is found under Human Resources → Record Leave, or the Record leave for a member button on Leave Approvals if you also approve.

This is not a request to the member. HR creates the leave record directly and it counts straight away; the member is only told afterwards and asked to acknowledge it. If you want the member to apply themselves, ask them outside the system and they use Apply Leave as normal.
1

Leave Approvals → Record leave for a member

Choose the member — their remaining balance per type is shown.

2

Type, dates, reason

The reason is required (at least 5 characters), e.g. “MC sent by WhatsApp on 3 Oct, did not apply”. Upload the MC if the type needs a document.

3

Save

It is Approved at once and deducted from the member's balance. It shows “Recorded by HR” with who recorded it. If the member does not have enough balance, the system stops with “Insufficient balance” — record the days the balance covers, and the rest as Unpaid Leave.

4

The member is told

They get a notification and a card on their dashboard — “Leave recorded for you” — until they click OK, noted. The approver sees whether and when they acknowledged.

If the member says the recorded leave is wrong, cancel it (approver) and record it again correctly — the balance is restored on cancel.

08a — Leave That Already Happened

Leave whose dates have already passed can still be put on record. Choose the route that fits:

SituationWhat to do
The member can still apply (preferred)The member uses Apply Leave with the past dates, a clear reason, and proof if any (e.g. the MC). It goes to the approver as Pending like any other application.
The member could not or did not apply (hospitalised, MC sent by email/WhatsApp, did not turn up)HR uses Record leave for a member: same dates and type, a reason (at least 5 characters) and the proof. It is approved on saving and the member acknowledges it.
Absence with no valid reason (unauthorised)Record it as Unpaid Leave so it does not use up paid leave. Any disciplinary follow-up is a separate HR matter, not part of the leave record.
Not enough balance leftRecord what the balance covers under the normal type, and the shortfall as Unpaid Leave.

Keep the proof (MC, email, message) attached to the record. Leave that has not happened yet should always be applied for normally.

08b — Emergency Leave

Emergency Leave (EL) is not a separate leave type with its own balance. It is a label the system adds when a leave is applied for with too little notice — when it starts within the emergency threshold of the leave type (2 days for the default Annual Leave setup). A leave whose start date has already passed counts as having no notice, so it is labelled EL automatically.

  • The days are taken from the normal Annual Leave balance (the leave type keeps pointing at Annual Leave); only the name shown on the application changes to “Emergency Leave”.
  • It applies whether the member applies themselves or HR records it.
  • Leave Report and Leave Summary count EL under the type it was taken from, and show it separately as “of which emergency” / the Emergency pattern.
  • If the Annual Leave balance is not enough, the request is stopped — record the shortfall as Unpaid Leave.

10

Leave Summary

Human Resources → Leave → Leave Summary (needs leave:summary). It shows at a glance who is away, who is running low on leave and who has requests waiting.

Overview cards

Team members (and total days taken), Away today (approved leave covering today), Waiting for approval (pending days and how many members) and No leave left (members who used up at least one leave type). Click a card to filter the table.

Filters and sorting

Chips: Everyone, Away today, Has pending, No leave left, Leave patterns — each with a count. Sort by name, most days taken, most pending or least leave left. Search by name.

Days left, with a bar

Each leave type shows days left “of” the year's total, with a bar for days taken (dark) and pending (amber). Red means below zero; amber text means none left.

Next leave

The next booked leave with how soon it starts (“in 5 days”, “tomorrow”), or “None booked”.

  • Days left = entitlement + carry-forward + earned credits + opening balance − opening used days − taken − pending.
  • Leave patterns: Mon/Fri leave (starts on a Monday or ends on a Friday), Emergency (recorded as emergency leave), Short notice (applied for less than 3 days ahead). Hover a tag for its meaning.
  • Click a member for a balance card per leave type, every application (with status badges) and approved days by month. Export everything to Excel. A “How to read this page” box at the bottom explains each column.
Patterns are prompts for a conversation, not a judgement — check the dates before drawing conclusions.
11

Leave Report

Human Resources → Leave → Leave Report — days of approved leave in a year.

By leave type

Each member's days per type against their entitlement. Emergency leave is counted under the type it was taken as.

By month

Each member's days per month, Jan–Dec, with totals.

Options: Only members who took leave, sort by name or most leave first, filter one member, export to Excel or PDF (the PDF shows only the columns used).

Scenarios

Worked examples of common situations. Dates are examples; remember that weekends are never counted, so leave for a Saturday or Sunday only has no working days and cannot be applied for or recorded.

Company rule used in these examples: a member who could not apply beforehand must apply on their first working day back. The system does not block a later application — the rule is company policy, and a late application is visible to the approver (the “applied … days after” note, and the Short notice pattern on the Leave Summary).

Scenario 1 — Emergency, member applies afterwards

User A has an emergency on Thursday 22/10/2026 and cannot apply beforehand. User A is back at work on Friday 23/10/2026.

  • Friday 23/10 (first working day back): User A opens Apply Leave, chooses Annual Leave, sets From and To to 22/10/2026, writes the reason (e.g. “family emergency”) and attaches proof if there is any.
  • The start date has already passed, so the system labels it Emergency Leave automatically. The 1 day is reserved from the Annual Leave balance as Pending.
  • The approver opens Leave Approvals and sees the application with User A’s balance (days left before and after). They approve or reject with a reason.
  • On approval it becomes Approved and the day is deducted from Annual Leave. The Leave Summary counts it under Emergency.
  • If User A does not apply by the deadline, HR can still put it on record (Scenario 3), and it is visible as late.

Scenario 2 — Emergency that spans a weekend

User B has an emergency on Friday 23/10/2026 and is also away Monday 26/10/2026; back on Tuesday 27/10.

  • User B applies once on Tuesday 27/10: From 23/10/2026, To 26/10/2026.
  • The weekend (24–25/10) is not counted, so the application is 2 days (Friday and Monday).
  • It is labelled Emergency Leave and follows the same approval as Scenario 1.

Scenario 3 — Member could not apply (MC sent by WhatsApp)

User C was hospitalised Tuesday 20/10 to Thursday 22/10/2026, sent the MC to HR by WhatsApp and did not apply in the system.

  • HR (with the leave:record permission) opens Record Leave and chooses User C.
  • Leave type Sick Leave, From 20/10/2026, To 22/10/2026 (3 working days). Reason: “MC from hospital sent by WhatsApp on 22 Oct; member did not apply”. Upload the MC.
  • Save: it is Approved at once, deducted from User C’s Sick Leave, and marked Recorded by HR.
  • User C is notified and, on the dashboard, clicks OK, noted. HR can see on the Leave Summary whether it has been acknowledged.

Scenario 4 — Absent without notice or valid reason

User D did not come to work on Monday 19/10/2026, could not be reached and has no proof.

  • HR records it as Unpaid Leave for 19/10/2026 with the reason, so it is on record and paid leave is not used.
  • The leave record is not a disciplinary decision. Any warning or action follows the company’s normal HR process, separately.

Scenario 5 — Emergency, but not enough Annual Leave left

User E has only 1 day of Annual Leave left and was absent for an emergency on Wed 21/10 to Fri 23/10/2026 (3 days).

  • A single application for 3 days is stopped with “Insufficient Annual Leave balance”.
  • Apply (or have HR record) 1 day as Annual Leave (labelled Emergency Leave), for example Wednesday 21/10.
  • Apply (or record) the other 2 days (22–23/10) as Unpaid Leave as a separate application.

Scenario 6 — HR recorded the wrong dates

HR recorded User C’s MC as 20–22/10, but the MC actually covers 21–23/10.

  • An approver cancels the wrong record — User C’s balance is restored.
  • HR records it again with the correct dates and the same proof. The member acknowledges the new record.

Scenario 7 — Approver checking a request

An approver reviews User F’s 5-day Annual Leave request.

  • On Leave Approvals, the Balance column shows “X left → Y”, and the approve dialog lists total available, used, pending, and remaining before and after this request.
  • If the request is more than User F has left, the result is shown in red with “Exceeds balance” as a warning. Balances are shown for the current year only.
